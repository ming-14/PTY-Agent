# 2026-08-04 修复 3 个关键 bug + 全量 e2e 回归

## 完成项
- 修复 `Result<T>::Value()` 在错误状态下触发 std::optional 空值解引用崩溃（Lessons-Learned #009）
  - `src/core/entities/Result.hpp`：`Value()` 增加 `has_value()` 检查，错误时抛 `std::logic_error`
  - 根因：`Value()` 直接 `value_.value()`，Err 状态时 `value_` 为空 optional，MSVC hardening 下直接崩溃
- 修复 `FrameCodec` 分片重组 use-after-free（Lessons-Learned #010）
  - `src/infra/ipc/FrameCodec.cpp`：先拷贝 `pieces`/`total_base64_size`/`original_type` 再 `erase`
  - 根因：`HandleDecodedMessage` 先 `fragment_buffers_.erase(it)` 再访问 `buf.pieces`（悬垂引用）
  - 影响：20MB 分片（21 帧）场景下最后一帧触发重组时访问已释放内存
- 修复 Shutdown race condition（Lessons-Learned #011）
  - `src/infra/ipc/NamedPipeServerImpl.cpp`：`Shutdown()` 新增 flush write_queue 步骤
  - 根因：`SendEvent(ShutdownComplete)` 只是入队，`Shutdown()` 立即 `CancelIoEx` 导致消息未写完
- 修复 `test_scenario_c_sample.py` 环境适应
  - NetworkBlocked 事件依赖 WFP/SOCKS5，Phase 5 已放弃 WFP 改为 capability-based
  - 非管理员模式下网络模块不可用，测试改为检查 Ready capabilities 决定是否验证
