# LLD-01：Job Object 模块（资源限制与级联控制）

## 1. 模块概述

| 项 | 内容 |
|----|------|
| 模块 | Job Object（资源限制 + IOCP 通知 + 级联终止） |
| 路径 | `src/infra/job/`、`src/core/ports/IJobObject.hpp` |
| 上游 | HLD §4.4（框架层）、§7.1（IJobObject 接口） |
| 下游 | Phase 1（核心实现） |
| 实现 Phase | Phase 1 |

### 职责
- 创建 Job Object（kill-on-close）
- 设置资源限制（CPU/内存/IO/进程数/UI）
- 绑定 IOCP 接收 Job 通知
- 进程分配到 Job
- 级联终止
- 查询会计信息

### 不职责
- 进程创建（IProcessLauncher 负责）
- AppContainer Token（IAppContainer 负责）
- 资源统计上报（IStatsCollector 负责，但读取 Job 会计信息）

---

## 2. 详细设计目标

| 目标 | 指标 |
|------|------|
| Job 创建延迟 | < 1ms |
| IOCP 通知延迟 | < 10ms（从事件发生到回调） |
| 资源限制精度 | 内存限制误差 < 1MB，CPU 时间精确到 ms |
| 级联终止延迟 | < 500ms（10 个进程内） |
| 会计信息查询 | < 1ms |

## 3. 数据模型

### 3.1 ResourceQuota（资源配额）

```cpp
// src/core/entities/ResourceQuota.hpp
struct ResourceQuota {
    // CPU 限制
    std::optional<uint64_t> cpu_ms;              // 单进程总 CPU 时间（ms）
    std::optional<uint32_t> cpu_rate_percent;    // CPU 占比上限（1-100）

    // 内存限制
    std::optional<uint64_t> memory_mb;           // 单进程提交内存上限
    std::optional<uint64_t> job_memory_mb;       // 整个 Job 内存上限

    // IO 限制（Win10+）
    std::optional<uint64_t> io_rate_bytes_per_sec;
    std::optional<uint64_t> io_rate_iops;

    // 进程/线程限制
    std::optional<uint32_t> max_processes;
    std::optional<uint32_t> max_threads;  // 注：Job 不直接限制线程数,通过 active process 间接

    // 超时
    std::optional<uint64_t> wall_clock_timeout_ms;  // 沙箱主循环定时器
    std::optional<uint64_t> cpu_timeout_ms;          // Job CPU 时间限制

    // UI 限制
    bool no_ui = true;

    // 子进程逃逸
    bool breakaway_ok = false;
};
```

### 3.3 JobNotification（通知事件）

```cpp
// src/core/entities/JobNotification.hpp
enum class JobNotificationType {
    EndOfJobTime,           // Job CPU 时间耗尽
    EndOfProcessTime,       // 单进程 CPU 时间耗尽
    ActiveProcessLimit,     // 进程数超限
    ProcessMemoryLimit,     // 单进程内存超限
    JobMemoryLimit,         // Job 内存超限
    ProcessExit,            // 进程退出（Phase 8 起：退出码查询失败时的兜底类型）
    ProcessExitNormal,      // Phase 8：进程正常退出（退出码 == 0）
    ProcessExitAbnormal,    // Phase 8：进程异常退出（退出码 != 0，含崩溃）
    ActiveProcessEmpty,     // Job 内无进程
    NewProcess,             // 新进程加入
    Unknown,                // 未识别消息（日志后忽略）
};

struct JobNotification {
    JobNotificationType type;
    uint32_t pid;                  // 相关进程 PID（ProcessExit/NewProcess 等）
    uint64_t timestamp_ms;

    // Phase 8 扩展字段
    std::string process_name;            // 进程名称（如 "cmd.exe"），NEW_PROCESS 填充
    std::string process_path;            // 进程完整路径，NEW_PROCESS 填充
    std::optional<uint32_t> exit_code;   // 退出码（仅退出类通知有效）
};
```

## 4. 核心类与接口定义

### 4.1 IJobObject（端口接口）

```cpp
// src/core/ports/IJobObject.hpp
class IJobObject {
public:
    virtual ~IJobObject() = default;

    // 创建 Job（kill-on-close）
    virtual Result<void> Create() = 0;

    // 设置资源限制
    virtual Result<void> SetResourceLimits(const ResourceQuota&) = 0;

    // 设置 UI 限制
    virtual Result<void> SetUiLimits(bool no_ui) = 0;

    // 分配进程到 Job
    virtual Result<void> AssignProcess(HANDLE process) = 0;

    // 级联终止所有进程
    virtual Result<void> TerminateAll(uint32_t exit_code) = 0;

    // 终止单个进程
    virtual Result<void> TerminateProcess(HANDLE process, uint32_t exit_code) = 0;

    // 查询会计信息
    virtual Result<JobAccountingInfo> QueryAccounting() const = 0;

    // 查询峰值内存
    virtual Result<uint64_t> QueryPeakMemory() const = 0;

    // 注册 IOCP 通知回调
    virtual Result<void> RegisterNotificationSink(IJobNotificationSink&) = 0;

    // 获取 Job 句柄（供 ProcessLauncher 使用）
    virtual HANDLE GetHandle() const = 0;

    // ----- Phase 8：Job 功能增强 -----

    // 查询 Job 内所有进程的 PID 列表
    // 内部两次调用 QueryInformationJobObject(JobObjectBasicProcessIdList)，
    // 两次调用间进程数增长（ERROR_MORE_DATA）时按新长度重试（最多 8 次）
    virtual Result<std::vector<uint32_t>> QueryProcessList() const = 0;

    // 查询单个进程退出码（OpenProcess + GetExitCodeProcess）
    // 进程仍在运行返回 STILL_ACTIVE (259)
    virtual Result<uint32_t> QueryProcessExitCode(uint32_t pid) const = 0;

    // 设置崩溃静默（JOB_OBJECT_LIMIT_DIE_ON_UNHANDLED_EXCEPTION）
    // true：Job 内未处理异常直接终止，不弹对话框/不触发 WER
    virtual Result<void> SetCrashSilent(bool silent) = 0;
};
```

### 4.3 JobObjectImpl（实现）

```cpp
// src/infra/job/JobObjectImpl.hpp
class JobObjectImpl : public IJobObject {
public:
    explicit JobObjectImpl(std::shared_ptr<ILogger>);
    ~JobObjectImpl() override;

    Result<void> Create() override;
    Result<void> SetResourceLimits(const ResourceQuota&) override;
    Result<void> SetUiLimits(bool no_ui) override;
    Result<void> AssignProcess(HANDLE process) override;
    Result<void> TerminateAll(uint32_t exit_code) override;
    Result<void> TerminateProcess(HANDLE process, uint32_t exit_code) override;
    Result<JobAccountingInfo> QueryAccounting() const override;
    Result<uint64_t> QueryPeakMemory() const override;
    Result<void> RegisterNotificationSink(IJobNotificationSink&) override;
    HANDLE GetHandle() const override { return job_handle_.get(); }

private:
    // 设置各类限制的内部方法
    Result<void> SetExtendedLimits(const ResourceQuota&);
    Result<void> SetCpuRateControl(uint32_t percent);
    Result<void> SetIoRateControl(uint64_t bytes_per_sec, uint64_t iops);
    Result<void> SetActiveProcessLimit(uint32_t max);
    Result<void> SetUiRestrictions(DWORD flags);

    // IOCP 通知线程
    void IocpLoop();

    // 翻译 IOCP 消息
    JobNotification TranslateMessage(DWORD message, DWORD pid);

    std::shared_ptr<ILogger> logger_;
    wil::unique_handle job_handle_;
    wil::unique_handle iocp_handle_;

    std::atomic<bool> running_{false};
    std::thread iocp_thread_;
    IJobNotificationSink* sink_{nullptr};
    std::mutex sink_mutex_;

    ResourceQuota quota_;
};
```

## 5. 详细设计

### 5.1 Job 创建流程

```
JobObjectImpl::Create()
    │
    ▼
CreateJobObjectW(nullptr, L"win-sandbox-<instance_id>")
    │  返回 job_handle
    ▼
设置 JOB_OBJECT_LIMIT_KILL_ON_JOB | JOB_OBJECT_LIMIT_BREAKAWAY_OK (按配置)
    │  通过 SetInformationJobObject(JobObjectExtendedLimitInformation)
    ▼
创建 IOCP: CreateIoCompletionPort(INVALID_HANDLE_VALUE, nullptr, 0, 0)
    │
    ▼
绑定 Job 到 IOCP:
    SetInformationJobObject(JobObjectAssociateCompletionPortInformation)
    │  CompletionKey = JOB_KEY
    │  CompletionPort = iocp_handle
    ▼
启动 IocpLoop 线程
    │
    ▼
返回成功
```

### 5.2 资源限制设置

#### 5.2.1 限制项映射表

| 配置项 | JobObject 信息类 | 限制标志 | 备注 |
|--------|-------------------|----------|------|
| `cpu_ms` | `JobObjectExtendedLimitInformation` | `JOB_OBJECT_LIMIT_JOB_TIME` | Per-job CPU time |
| `cpu_rate_percent` | `JobObjectCpuRateControlInformation` | `JOB_OBJECT_CPU_RATE_CONTROL_ENABLE` + `JOB_OBJECT_CPU_RATE_CONTROL_HARD_CAP` | Win8+ |
| `memory_mb` | `JobObjectExtendedLimitInformation` | `JOB_OBJECT_LIMIT_PROCESS_MEMORY` | Per-process |
| `job_memory_mb` | `JobObjectExtendedLimitInformation` | `JOB_OBJECT_LIMIT_JOB_MEMORY` | Per-job |
| `io_rate_bytes_per_sec` | `JobObjectIoRateControlInformation` | `JOB_OBJECT_IO_RATE_CONTROL_ENABLE` | Win10+ |
| `max_processes` | `JobObjectExtendedLimitInformation` | `JOB_OBJECT_LIMIT_ACTIVE_PROCESS` | Win8+ |
| `no_ui` | `JobObjectBasicUIRestrictions` | `JOB_OBJECT_UILIMIT_*` 组合 | 见 5.2.4 |
| `breakaway_ok` | `JobObjectExtendedLimitInformation` | `JOB_OBJECT_LIMIT_BREAKAWAY_OK` (反向) | 默认 false=禁止逃逸 |

#### 5.2.2 ExtendedLimits 设置

```cpp
JOBOBJECT_EXTENDED_LIMIT_INFORMATION ext = {};
ext.BasicLimitInformation.LimitFlags |= JOB_OBJECT_LIMIT_KILL_ON_JOB;
if (quota.cpu_ms) {
    ext.BasicLimitInformation.PerJobUserTimeLimit = MsTo100ns(*quota.cpu_ms);
    ext.BasicLimitInformation.LimitFlags |= JOB_OBJECT_LIMIT_JOB_TIME;
}
if (quota.memory_mb) {
    ext.ProcessMemoryLimit = MBToBytes(*quota.memory_mb);
    ext.BasicLimitInformation.LimitFlags |= JOB_OBJECT_LIMIT_PROCESS_MEMORY;
}
if (quota.job_memory_mb) {
    ext.JobMemoryLimit = MBToBytes(*quota.job_memory_mb);
    ext.BasicLimitInformation.LimitFlags |= JOB_OBJECT_LIMIT_JOB_MEMORY;
}
if (quota.max_processes) {
    ext.BasicLimitInformation.ActiveProcessLimit = *quota.max_processes;
    ext.BasicLimitInformation.LimitFlags |= JOB_OBJECT_LIMIT_ACTIVE_PROCESS;
}
if (!quota.breakaway_ok) {
    ext.BasicLimitInformation.LimitFlags |= JOB_OBJECT_LIMIT_BREAKAWAY_OK; // 反向：禁止
    // 注：实际是设置 JOB_OBJECT_LIMIT_BREAKAWAY_OK 表示允许逃逸
    // 不设置该 flag = 禁止逃逸
}
SetInformationJobObject(job_handle_, JobObjectExtendedLimitInformation, &ext, sizeof(ext));
```

#### 5.2.3 CPU Rate Control（Win8+）

```cpp
// CPU Rate Control 标志说明（MSDN）：
//   ENABLE      必须，开启 CPU 速率控制
//   HARD_CAP    硬上限（超出即挂起，而非调度延迟）
//   WEIGHT_BASED 用 Weight 字段（1-9 权重），与 CpuRate 互斥
//   不设 WEIGHT_BASED：默认使用 CpuRate 字段（0.01% 单位，100% = 10000）
//
// 注意：不能同时设置 WEIGHT_BASED + CpuRate，否则 SetInformationJobObject
// 会失败。LLD-01 v1 原文曾同时设置二者，导致 cpu_rate_percent 配置失效，
// 已修复。
JOBOBJECT_CPU_RATE_CONTROL_INFORMATION cpu = {};
cpu.ControlFlags = JOB_OBJECT_CPU_RATE_CONTROL_ENABLE
                 | JOB_OBJECT_CPU_RATE_CONTROL_HARD_CAP;
if (quota.cpu_rate_percent) {
    cpu.CpuRate = *quota.cpu_rate_percent * 100; // 单位 0.01%（50% → 5000）
}
SetInformationJobObject(job_handle_, JobObjectCpuRateControlInformation, &cpu, sizeof(cpu));
```

#### 5.2.4 UI 限制

```cpp
DWORD ui_flags = 0;
if (quota.no_ui) {
    ui_flags |= JOB_OBJECT_UILIMIT_HANDLES        // 禁止访问其他进程窗口句柄

}
SetInformationJobObject(job_handle_, JobObjectBasicUIRestrictions, &ui_flags, sizeof(ui_flags));
```

### 5.3 IOCP 通知处理

#### 5.3.1 IocpLoop

```cpp
void JobObjectImpl::IocpLoop() {
    while (running_) {
        DWORD bytes_transferred = 0;
        ULONG_PTR completion_key = 0;
        LPOVERLAPPED overlapped = nullptr;

        BOOL ok = GetQueuedCompletionStatus(
            iocp_handle_.get(),
            &bytes_transferred,
            &completion_key,
            &overlapped,
            INFINITE);

        if (!running_) break;

        if (!ok) {
            DWORD err = GetLastError();
            logger_->warn("IOCP wait failed: {}", err);
            continue;
        }

        if (completion_key != JOB_KEY) continue;

        // bytes_transferred 实际是 Job 消息 ID
        DWORD message = bytes_transferred;
        DWORD pid = reinterpret_cast<DWORD>(overlapped);

        JobNotification notif = TranslateMessage(message, pid);

        std::lock_guard lock(sink_mutex_);
        if (sink_) sink_->OnNotification(notif);
    }
}
```

#### 5.3.2 消息翻译表

| IOCP Message | JobNotificationType | 含义 |
|--------------|---------------------|------|
| `JOB_OBJECT_MSG_END_OF_JOB_TIME` | `EndOfJobTime` | Job CPU 时间耗尽 |
| `JOB_OBJECT_MSG_END_OF_PROCESS_TIME` | `EndOfProcessTime` | 单进程 CPU 时间耗尽 |
| `JOB_OBJECT_MSG_ACTIVE_PROCESS_LIMIT` | `ActiveProcessLimit` | 进程数超限 |
| `JOB_OBJECT_MSG_PROCESS_MEMORY_LIMIT` | `ProcessMemoryLimit` | 单进程内存超限 |
| `JOB_OBJECT_MSG_JOB_MEMORY_LIMIT` | `JobMemoryLimit` | Job 内存超限 |
| `JOB_OBJECT_MSG_EXIT_PROCESS` | `ProcessExit` | 进程退出 |
| `JOB_OBJECT_MSG_ACTIVE_PROCESS_ZERO` | `ActiveProcessEmpty` | Job 内无进程 |
| `JOB_OBJECT_MSG_NEW_PROCESS` | `NewProcess` | 新进程加入 |

### 5.4 进程分配

```cpp
Result<void> JobObjectImpl::AssignProcess(HANDLE process) {
    if (!AssignProcessToJobObject(job_handle_.get(), process)) {
        DWORD err = GetLastError();
        if (err == ERROR_ACCESS_DENIED) {
            // 进程已在其他 Job 中
            logger_->error("Process already in another job");
            return Err(ErrorCode::JOB_PROCESS_ALREADY_IN_JOB);
        }
        return Err(ErrorCode::JOB_ASSIGN_FAILED);
    }
    return Ok();
}
```

### 5.5 级联终止

```cpp
Result<void> JobObjectImpl::TerminateAll(uint32_t exit_code) {
    if (!TerminateJobObject(job_handle_.get(), exit_code)) {
        return Err(ErrorCode::JOB_TERMINATE_FAILED);
    }
    return Ok();
}
```

注：由于 `JOB_OBJECT_LIMIT_KILL_ON_JOB` 标志，Job 句柄关闭时也会自动终止所有进程。

### 5.6 会计信息查询

```cpp
Result<JobAccountingInfo> JobObjectImpl::QueryAccounting() const {
    JOBOBJECT_BASIC_AND_IO_ACCOUNTING_INFORMATION info = {};
    if (!QueryInformationJobObject(
            job_handle_.get(),
            JobObjectBasicAndIoAccountingInformation,
            &info, sizeof(info), nullptr)) {
        return Err(ErrorCode::JOB_QUERY_FAILED);
    }

    JobAccountingInfo result;
    result.total_user_time = info.BasicInfo.TotalUserTime;
    result.total_kernel_time = info.BasicInfo.TotalKernelTime;
    result.read_operation_count = info.IoInfo.ReadOperationCount;
    result.write_operation_count = info.IoInfo.WriteOperationCount;
    result.read_transfer_count = info.IoInfo.ReadTransferCount;
    result.write_transfer_count = info.IoInfo.WriteTransferCount;
    result.total_processes = info.BasicInfo.TotalProcesses;
    result.active_processes = info.BasicInfo.ActiveProcesses;
    result.total_page_faults = info.BasicInfo.TotalPageFaults;
    // 峰值内存需单独查询
    return Ok(result);
}

Result<uint64_t> JobObjectImpl::QueryPeakMemory() const {
    JOBOBJECT_EXTENDED_LIMIT_INFORMATION ext = {};
    if (!QueryInformationJobObject(
            job_handle_.get(),
            JobObjectExtendedLimitInformation,
            &ext, sizeof(ext), nullptr)) {
        return Err(ErrorCode::JOB_QUERY_FAILED);
    }
    return Ok(static_cast<uint64_t>(ext.PeakProcessMemoryUsed));
}
```

## 6. 错误处理与边界情况

### 6.1 错误码表

| ErrorCode | 含义 | 处理 |
|-----------|------|------|
| `JOB_CREATE_FAILED` | CreateJobObjectW 失败 | 启动失败 |
| `JOB_SET_LIMIT_FAILED` | SetInformationJobObject 失败 | 按限制项降级或失败 |
| `JOB_ASSIGN_FAILED` | AssignProcessToJobObject 失败 | 进程启动失败 |
| `JOB_PROCESS_ALREADY_IN_JOB` | 进程已在其他 Job | 检测 IsProcessInJob |
| `JOB_TERMINATE_FAILED` | TerminateJobObject 失败 | 记录日志 |
| `JOB_QUERY_FAILED` | QueryInformationJobObject 失败 | 返回空统计 |
| `JOB_IOCP_CREATE_FAILED` | CreateIoCompletionPort 失败 | 启动失败 |
| `JOB_CPU_RATE_NOT_SUPPORTED` | CPU Rate Control 不可用 | 降级（不设置） |
| `JOB_IO_RATE_NOT_SUPPORTED` | IO Rate Control 不可用 | 降级（不设置） |

### 6.2 边界情况

| 情况 | 处理 |
|------|------|
| 父进程已在 Job 中 | `IsProcessInJob` 检测；嵌套 Job 受限 |
| Win8 以下系统 | 跳过 CPU Rate Control、IO Rate Control |
| 普通用户权限 | 跳过 IO Rate Control（需管理员） |
| Job 句柄泄漏 | WIL `unique_handle` RAII 保证释放 |
| IOCP 线程崩溃 | try-catch 包裹，记录日志，不崩溃主进程 |
| TerminateAll 时进程已在退出 | 忽略 ERROR_INVALID_PARAMETER |
