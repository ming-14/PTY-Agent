- 权限检测（`TokenElevation`、`GetTokenInformation`）

  - 异步 API（`AsyncSandboxClient`，基于 asyncio）
  - 上下文管理器（`with SandboxClient() as sb:`）
  - 事件迭代器（`for event in sb.events():`）
- e2e 测试套件：4 类场景全覆盖
- 文档：用户手册、API 参考、部署指南
- CI 配置（GitHub Actions）

## 5. 任务清单

### T7.1 PermissionDetector
- `src/adapters/PermissionDetector.hpp/cpp`
- `CheckTokenElevation`：检测当前进程是否提升
- `GetTokenInformation(TokenElevation)`：获取提升状态
- 输出 `PermissionMode`（Admin / StandardUser）
- 输出 `CapabilityReport`：列出每个能力的可用性

**验收**：管理员运行返回 Admin + 全能力；普通用户运行返回 StandardUser + 降级能力集。

### T7.2 CapabilityReport 事件
- 启动时发送 `CapabilityReport` 事件
- payload：
  - `permission_mode`：admin / standard_user
  - `enabled_features`：["job", "appcontainer", "wfp", "etw_kernel", ...]
  - `disabled_features`：["cpu_rate_control_v2", "io_rate_control", "wfp_callout", "etw_kernel_session", ...]
  - `reasons`：每项降级原因

**验收**：Python 端能获取 CapabilityReport 并判断可用功能。

### T7.3 Job Object 降级
- `JobObjectImpl` 检测权限
- 普通用户模式：
  - 跳过 `JobObjectCpuRateControlInformation`（需管理员）
  - 跳过 `JobObjectIoRateControlInformation`（需管理员）
  - 保留：内存限制、CPU 时间限制、active process 限制、UI 限制
- 降级时日志记录

**验收**：普通用户模式下 Job 创建成功，降级项记录在 CapabilityReport。

### T7.4 WFP 降级
- `WfpEngineImpl` 检测权限
- 普通用户模式：
  - 跳过 WFP 注册（需管理员）
  - 网络策略强制为 `deny-all`（仅靠 AppContainer）
  - `allowlist` / `proxy` / `full` 策略在普通用户下降级为 `deny-all`
- 降级时日志记录 + CapabilityReport 标记

**验收**：普通用户模式下网络策略强制 deny-all，不崩溃。

### T7.5 ETW 降级
- `EtwMonitorImpl` 检测权限（`IsElevated`）
- 普通用户模式：
  - 跳过 NT Kernel Logger（需管理员）
  - 跳过内核 provider（FileIo / Registry / TcpIp）
  - 进程事件：`Toolhelp32Snapshot` 轮询进程列表（ProcessStart/Stop）
  - 文件事件：`ReadDirectoryChangesW` 递归监控 `degraded_monitor_dirs` 配置目录（2026-08-06 扩展）
  - 网络事件：`GetExtendedTcpTable`/`GetUdpTable` 轮询（TcpConnect/UdpSend，2026-08-06 扩展）
  - 注册表事件仍不可用（无法全局监控）
- 首次轮询只建基线，不产生全系统进程噪音（2026-08-06 修复）
- 降级时日志记录

**验收**：普通用户模式下 ETW 不崩溃，CapabilityReport 标记监控降级；
`force_degraded: true` 可在管理员环境验证降级路径（`test_degraded_monitor.py` 6/6 PASS）。

### T7.6 残留清理
- 启动时扫描：
  - `%LOCALAPPDATA%\Packages\win-sandbox-*`：清理无主 AppContainer Profile
  - ETW session：`QueryAllTracesW` 查找 `win-sandbox-etw-*` 并停止
  - WFP filter：查询并删除残留 filter
- 清理日志

**验收**：沙箱异常退出后重启，残留资源被清理。

### T7.7 Python 包封装
- `python/pyproject.toml`：
  - 构建系统：hatchling
  - 依赖：无（仅标准库）

- `python/setup.py`（如需兼容旧 pip）
- `package_data`：`bin/sandbox.exe`
- `entry_points`：可选 CLI（`win-sandbox` 命令）
- `win_sandbox/__init__.py`：导出公开 API

**验收**：`pip install -e .` 成功，`import win_sandbox` 可用。

### T7.8 Python 异步 API

### PermissionDetector 实现

```cpp
struct CapabilityReport {
    PermissionMode mode;                    // Admin / StandardUser
    std::vector<CapabilityItem> capabilities; // 各模块可用性 + 降级原因
};
```

检测项：
- `CheckTokenElevation`：TokenElevation → Admin / StandardUser
- `CheckAppContainer`：是否可创建 AppContainer
- `CheckEtw`：是否可启动 ETW 内核 session
- `CheckWfp`：是否可注册 WFP callout
- `CheckFileSystem`：文件系统隔离是否可用
- `CheckPipeSecurity`：管道 DACL 是否可用

### Ready 事件 payload 变更

Ready 事件新增 `capabilities` 字段：
```json
{
  "type": "ready",
  "payload": {
    "pipe_name": "...",
    "capabilities": {
      "phase": 7,
      "mode": "standard_user",
      "modules": {
        "app_container": {"available": true},
        "etw": {"available": false, "degraded_reason": "..."},
        "network": {"available": false, "degraded_reason": "..."},
        ...
      }
    }
  }
}
```
