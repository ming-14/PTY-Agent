# 2048

一个用 Python 实现的 2048 游戏，方向键操控

# 启动方式

```bash
app.py exec game2048 -c "随便写" --plugin 2048
```

**命令行参数**（直接运行 `main.py`）：

- `simple` — 简单模式：只输出棋盘纯文本（空位 `-`），无提示/奖杯等元素
- `--new` — 启动前清空存档，强制新开局
- 可组合：`python main.py --new simple`

# 注意事项

0. 不要使用`--keep-ansi`
1. 目标是合成32，用户要求2048那就2048
2. 出现奖杯请根据指引使用鼠标
