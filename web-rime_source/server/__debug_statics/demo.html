快速参考

桌面模式：使用物理键盘输入，面板显示候选词，工具栏提供选项开关。
移动模式：虚拟键盘支持震动反馈，点击输入，长按可输入候选变体。
TKL 模式：87键悬浮虚拟键盘 + 独立候选词面板，修饰键支持组合键发送。
