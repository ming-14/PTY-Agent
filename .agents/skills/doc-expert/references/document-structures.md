# Document Structure Templates

This reference provides standard structures for various technical document types.

---

## PRD Standard Structure

```
1. Document Information (version, author, date, status)
2. Background and Objectives
3. User Roles and Scenarios
4. Functional Requirements (user stories + acceptance criteria)
5. Non-Functional Requirements (performance, security, compatibility)
6. Interaction / Prototype Specifications (if applicable)
7. Data Requirements
8. Dependencies and Constraints
9. Milestones / Schedule
10. Appendix
```

## BRD Standard Structure

```
1. Executive Summary
2. Business Background and Pain Points
3. Business Objectives and Success Metrics (KPI/OKR)
4. Scope (In Scope / Out of Scope)
5. Stakeholders
6. Current vs Target Business Process
7. Risks and Assumptions
8. Estimated ROI
9. Next Steps
```

## HLD Standard Structure

```
1. Document Information
2. Background and Objectives
3. System Architecture Diagram
4. Module / Service Decomposition
5. Core Technology Selection and Rationale
6. Data Flow / Call Chain Description
7. Key Interface Definitions (High-Level)
8. Non-Functional Design (availability, scalability, security)
9. Deployment Architecture
10. Risks and Open Decisions
```

## LLD Standard Structure

```
1. Module Overview
2. Detailed Design Objectives
3. Data Model / Database Design
4. Core Classes / Interface Definitions
5. Detailed Flow Diagrams (sequence / activity diagrams)
6. Error Handling and Edge Cases
7. Performance and Resource Estimation
8. Testing Key Points
```

## Technical Solution / Solution Review Standard Structure

```
1. Background and Problem Description
2. Objectives and Constraints
3. Solution 1: Description + Pros/Cons + Applicable Scenarios
4. Solution 2: Description + Pros/Cons + Applicable Scenarios
5. Solution Comparison Table
6. Recommended Solution and Rationale
7. Implementation Steps and Milestones
8. Risk Analysis and Mitigation
9. Open Issues / Pending Confirmations
```
