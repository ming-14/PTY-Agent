# 目录树文件编写规范

本目录存放目录结构。本文件规定这类文档的**编写规范**，供后续维护与新增时遵循

## 文档组成

本目录下的按区域拆分文件：
- `src.md` —— `src/` 主包
- `web-static.md` —— `src/web/static/` 前端静态资源

子包自身的文件树文档位于各子包的 `docs/FILESTREE.md`：
- `tests/docs/FILESTREE.md` —— `tests/` 测试套件
- `web_rime/docs/FILESTREE.md` —— `web_rime/` Rime 输入法
- `sandbox/docs/FILESTREE.md` —— `sandbox/` C++ 沙箱（win_sandbox_native pybind11）

> 后续若有新的子包，可以创建新的 md 文件（本目录或子包 `docs/` 下）

## 总体格式

示例：

````markdown
# src/ 主包

> 主 Python 包

```
src/
├── __main__.py              # CLI 入口（参数解析 + 命令派发）
├── config/                  # ═══════ 配置中心 ═══════
│   ├── __init__.py
│   └── common.toml          # 共有配置
└── vnc/                     # ═══════ VNC 远程桌面层 ═══════
    └── adapter.py           # VNC 适配器
```
````

## 规范

目录树必须**完全对应真实文件系统**，不得臆造：

1. **禁止写不存在的文件，禁止写变更历史，禁止对历史文件做标注说明**。若历史上存在但现已删除/改名，绝对禁止提及，不写额外说明，保证文档干净

2. **第三方/生成内容做摘要**，不逐文件展开：
   - 词典 `.bin`/`.yaml` 等批量生成产物用父目录注释概括（如 `dict/  # 词典（double-pinyin / luna-pinyin / ...）`），不为每个文件单列一行；
   - `build`，`__pycache__/`等由`.gitignore`忽略的文件不列入文件树

3. 行尾注释中出现跨文件引用时，用相对链接指向同目录其他文件，例如：`完整结构见 [web-static.md](web-static.md)`。

### 节点注释

- **每个文件/目录节点**都应在行尾用 `#` 给出简短中文说明（用途、技术要点、属于哪一层）。
- 重大子系统用"横幅"注释突出层级，例如：

  ```
  ├── auth/                  # ═══════ 认证层（可插拔认证与消息签名） ═══════
  ```
