# pty-agent 输出一览

> 列出所有可能的输出场景，包含自然语言模式的具体输出格式。

---

## 1. 输出模式

| 模式 | stdout 内容 | stderr 内容 |
|------|-------------|-------------|
| **自然语言模式**（唯一） | 程序输出 + 元数据（纯文本） | `--color` 启用时元数据走 stderr |

程序实际输出 → **stdout**（纯文本）
元数据/调试信息 → **stdout**（默认）或 **stderr**（`--color` 启用时终端着色输出）

守护进程日志不会泄漏到 stderr。

---

## 2. 命令响应输出

### 2.1 exec / send / read — result 类型

守护进程返回 `type` 为 `exec` / `send` / `read` 的 result 响应，客户端格式化输出。

#### 自然语言模式

```
Python 3.11.9 ...
>>>

# ── session ────────────────────────
# matched | running
# session id: myid
# pty type: subprocess
# program: python -i -u
# started at: 2026-06-22 14:32:15
# current time: 2026-06-22 14:32:20

# ── debug ────────────────────────
# process tree: PID 1234 (C:\Python311\python.exe)

# ── events (1) ────────────
# [+]  [14:32:15] PID 1234 created

# ── offset ────────────────────────
# 1234
```

各段说明：

| 段 | 条件 | 内容 |
|----|------|------|
| 程序输出 | `output` 非空 | 终端实际输出文本（stdout） |
| session 段 | 有触发/状态信息 | `matched`/`timeout`/`ended` 等状态 + 会话元数据 |
| ⚠ 警告 | `warning` 非空 | 警告信息（如"会话已结束"） |
| debug 段 | 有进程树/GUI 窗口 | 进程树列表 + GUI 窗口详情 |
| events 段 | 有待处理事件 | 事件列表（`[+]` 创建 / `[-]` 退出 / `[!!]` 崩溃 / `[W]` GUI） |
| error 段 | `error_message` 非空 | 错误信息 |
| offset 段 | `output_offset > 0` | 输出偏移量 |

**原因标签**（session 段首行）：`matched`（触发命中）/ `timeout`（等待超时）/ `idle_timeout`（输出静默超时）/ `ended`（程序退出）/ `crashed`（进程崩溃）/ `gui detected`（检测到 GUI 窗口）/ `ok`（无触发条件直接返回）。

**程序状态**：`running`（运行中）或 `ended`（已结束，带 `(exit=N)` 退出码）。

`--no-debug` 或 `--default debug off` 时隐藏 debug 段、events 段（进程树/GUI 窗口/事件）。

### 2.2 list — ok 类型（会话列表）

有会话：
```
# ── sessions (2) ──────
#   [web] python -i -u  [running, pending 3]
#   [gcc] g++ main.cpp  [ended]
```

无会话：
```
# no active sessions
```

### 2.3 kill — ok 类型

无输出（响应中的 `note` 提示"会话 xxx 已终止"由守护进程处理时输出）。

### 2.4 closewin — ok 类型

成功：
```
window 0x001403AA closed
```

失败：
```
window 0x001403AA close failed
```

### 2.5 stop — ok 类型

无输出（守护进程信息由 `stop_daemon()` 的 `_safe_print` 输出，见第 3 节）。

### 2.6 error 类型

所有错误响应格式统一。

```
error: 会话 'xxx' 不存在
```

输出到 stderr。

常见错误消息：

| 场景 | error 内容 |
|------|-----------|
| 会话不存在 | `会话 'xxx' 不存在` |
| 会话已结束 | `会话 'xxx' 已结束，请先 kill 后重新 exec` |
| 缺少会话 id | `缺少会话 id` |
| 缺少 command | `缺少 command 参数` |
| 认证失败 | `认证失败` |
| 未知指令 | `未知指令类型: xxx` |
| 服务器内部错误 | `服务器内部错误` |
| 写入输入失败 | `写入输入失败` |
| 启动会话失败 | `启动会话失败` |
| 参数过长 | `参数 'xxx' 过长（最多 N 字符）` |
| 无效正则 | `无效的正则表达式: xxx` |
| 无效行范围 | `无效的行范围: xxx` |
| 缺少 hwnd | `缺少 hwnd 参数` |
| 关闭窗口失败 | `关闭窗口失败` |

## 3. 守护进程生命周期信息

由 `start_daemon()` / `stop_daemon()` 内部 `_safe_print()` 输出。在 `exec`/`send`/`read`/`list` 等命令自动启动守护进程时也会触发。

纯文本输出到 stdout：

```
[pty-agent] 守护进程已启动
[pty-agent] 可用 shell: cmd (...), powershell (...), pwsh (...)
```

| 场景 | 输出 |
|------|------|
| 守护进程已在运行 | `[pty-agent] 守护进程已在运行中` |
| 守护进程已启动 | `[pty-agent] 守护进程已启动` |
| 可用 shell 信息 | `[pty-agent] 可用 shell: cmd (...), powershell (...), pwsh (...), bash (不可用)` |
| 守护进程启动失败（超时） | `[pty-agent] 守护进程启动失败（超时）` |
| 守护进程未运行 | `[pty-agent] 守护进程未运行` |
| 停止失败（信箱满） | `[pty-agent] 停止失败: 请求信箱已满` |
| 停止守护进程失败（超时） | `[pty-agent] 停止守护进程失败（超时）` |
| 共享内存停止失败 | `[pty-agent] 共享内存停止失败: <异常>` |
| 已强制终止 | `[pty-agent] 已强制终止守护进程 (PID 12345)` |
| 强制终止失败 | `[pty-agent] 强制终止失败: <异常>` |
| 守护进程已停止 | `[pty-agent] 守护进程已停止` |
| 守护进程启动失败（异常） | `[pty-agent] 守护进程启动失败: <异常>` |

## 4. 非命令响应输出

以下输出不来自守护进程响应，由客户端 `__main__.py` 直接生成。

### 4.1 配置查询（`--show-config`）

```
当前调用配置:
  debug = on
  encoding = (未设置)
  keep_ansi = off
  newline = off
  timeout = 120.0
  # 注: 这些默认值仅在有子命令（如 exec/send）时生效，仅作查询参考
```

### 4.2 帮助文本（无子命令）

argparse 默认帮助文本输出到 stdout。

### 4.3 警告信息

#### `--default` 单独使用

```
警告: --default 仅在与子命令（如 exec/send）配合时有效，单独使用不会产生效果
  已设置临时值: timeout = 30
```

输出到 stderr。

#### `--idle-after-first-output` 缺少 `--idle-timeout`

```
--idle-after-first-output 需要配合 --idle-timeout 使用，单独设置无效（当前未启用静默超时检测）
```

输出到 stderr。

#### `--default` 键名无效

```
无效的配置键: 'xxx'
```

输出到 stderr，然后 `sys.exit(1)`。

### 4.4 客户端异常

#### KeyboardInterrupt（Ctrl+C）

```
操作被用户中断
```

输出到 stderr。

#### 未捕获异常

```
错误: <异常信息>
```

输出到 stderr。

### 4.5 客户端请求错误（transport.py）

以下错误输出到 **stderr**：

| 场景 | stderr 输出 |
|------|------------|
| 启动守护进程失败 | `error: failed to start daemon` |
| 请求信箱已满 | `error: 请求信箱已满，请稍后重试` |
| 守护进程响应超时 | `error: 守护进程响应超时` |

### 4.6 守护进程无响应

```
error: 守护进程响应超时
```

输出到 stderr。
