# pty-agent 命令行交互参考

> 完整命令参考，面向**终端用户**。开发指南见 `doc/instruction.md`。

---

## 通用选项

以下选项适用于所有子命令（`start` / `stop` / `exec` / `send` / `read` / `list` / `events` / `kill` / `closewin`），**放子命令前后均可**：

| 选项 | 说明 |
|------|------|
| `--encoding <编码>` | 指定终端编码，本次调用记忆 |
| `--no-debug` | 禁用响应中的 debugInformation 输出（进程树/GUI 窗口/事件） |
| `--show-config [KEY]` | 查看当前调用配置值 |
| `--default <KEY> <VALUE>` | 临时覆盖本次调用的默认配置（可用键：`timeout`/`newline`/`keep-ansi`/`encoding`/`debug`/`send-eol`/`always-return-snapshot`/`response-format`/`svg-compression-level`，`<VALUE>` 是配置值或 `on`/`off`；`send-eol` 可选 `lf`/`crlf`/`cr`/`none`；支持多个 `--default`；按 session 持久化到守护进程） |

示例：
```powershell
#  禁用 debug 输出
pty-agent --no-debug exec test -c "cmd" -t "ok"
pty-agent exec test -c "cmd" -t "ok" --no-debug

#  指定编码
pty-agent --encoding utf-8 exec test -c "cmd" -t "ok"
```

## 临时配置管理

### 设置临时配置

```powershell
pty-agent --default timeout 30                           # 临时超时 30 秒
pty-agent --default newline on                            # 临时仅换行后检查触发
pty-agent --default keep-ansi on                          # 临时保留 ANSI 转义序列
pty-agent --default encoding gbk                           # 临时终端编码 gbk
pty-agent --default debug off                              # 临时禁用 debug 输出
pty-agent --default send-eol cr                            # 临时 send 追加 \r（PTY 回车）
pty-agent --default send-eol none                          # 临时 send 不追加行尾符（TUI 按键）
```

> **注意**：`--default` 仅在与子命令（如 `exec`/`send`）配合时有效。单独使用会打印警告并无效。`--default` 设置的值按 session 持久化到守护进程，后续对该 session 的调用自动读取。支持多个 `--default`（如 `--default always-return-snapshot on --default response-format svg`）。

```powershell
pty-agent exec build -c "gcc main.cpp" --default timeout 60   # 
pty-agent --default timeout 60 exec build -c "gcc main.cpp"   #  放前面也行
pty-agent --default timeout 30                                  #  警告：单独使用无效
```

### 查看配置

```powershell
pty-agent --show-config                    # 查看全部配置
pty-agent --show-config timeout             # 查看单项配置
pty-agent --show-config encoding
```

展示的配置值仅作查询参考，实际上只有配合子命令时才会生效。`--default` 设置的值按 session 持久化到守护进程。

## 命令一览

```
pty-agent [通用选项] start                        启动守护进程
pty-agent [通用选项] stop                         停止守护进程
pty-agent [通用选项] list                         列出所有会话
pty-agent [通用选项] exec <id> -c "<cmd>"         启动会话
pty-agent [通用选项] send <id> "<输入>"            发送输入
pty-agent [通用选项] read <id>                    读取输出
pty-agent [通用选项] events <id>                  查看所有事件
pty-agent [通用选项] kill <id>                    终止会话
pty-agent [通用选项] closewin <id> <hwnd>         关闭 GUI 窗口
pty-agent [通用选项] mouse <id> <动作>             发送鼠标动作
```

> 自动启动：首次执行 `exec`/`send`/`read`/`list`/`events` 等命令时，若守护进程未运行，客户端自动启动守护进程。不再需要手动 `start`。

## 命令详解

### start / stop

```powershell
pty-agent start        # 启动后台守护进程
pty-agent stop         # 停止守护进程
```

守护进程以独立子进程方式运行，不占用终端。首次调用其他命令时也会自动启动。

### exec — 执行命令

```powershell
pty-agent exec myid -c "python -i -u" -t ">>>" --timeout 10
```

| 参数 | 说明 |
|------|------|
| `-c, --command` | **必填**。要执行的命令字符串（默认经 shell 执行，支持 `&&`、`2>&1`、`\|` 等 shell 语法） |
| `--force-pty-mode` | 强制模式：忽略命令中的 shell 操作符检测，原样执行 |
| `-t, --trigger` | 触发条件（正则），匹配后返回输出 |
| `--timeout` | 等待超时秒数（默认 120，可通过 `--default timeout` 临时修改） |
| `--idle-timeout` | 输出静默超时（秒）。程序持续 N 秒无新输出时触发返回 |
| `--idle-after-first-output` | 仅在首次输出后才开始检测静默超时（初始不检测） |
| `--encoding` | 终端编码（utf-8 / gbk），默认自动探测或本次调用记忆 |
| `--newline` | 仅在换行后检查触发 |
| `--full` | 返回全部累积输出而非仅新输出 |
| `--keep-ansi` | 保留终端颜色/样式码（默认过滤；清屏/光标等控制序列始终保留） |
| `--cwd <path>` | 子进程工作目录（默认为调用者工作目录） |
| `--env KEY=VALUE` | 子进程额外环境变量，可指定多个（合并到继承的环境中） |
| `--snapshot-mode` | 快照模式：返回终端屏幕快照而非原始 VT 序列。支持 `--trigger`（匹配快照文本）、`--idle-timeout`（检测屏幕无变化）、`--idle-after-first-output`。会话进入此模式后，`send`/`read` 自动返回快照 |
| `-s, --snapshot-diff` | 仅返回屏幕变化的行（需快照模式，stream 格式；首次返回完整快照，后续只返回变化行，格式为 `行号:内容`；与 `--response-format svg` 互斥） |
| `-o, --output <path>` | 输出到文件：`.svg`=矢量图（零依赖）；`.png`/`.jpg`/`.bmp`=位图（需 Pillow，Windows 下 GDI+BuiltinGlyphs 几何图元渲染消除字符间隙）；`.txt`/其他=纯文本（非 snapshot 模式下直接写入 outputStream，不是屏幕快照）。图片输出需搭配 `--snapshot` 或 `--snapshot-mode` |
| `--response-format <stream\|svg>` | 响应格式选择：`stream`=默认 JSON 格式输出；`svg`=返回 SVG 矢量图（JSON 包装，需 PTY 会话的屏幕缓冲区） |
| `--svg-compression-level <0\|1\|2>` | SVG 压缩等级：0=不压缩；1=轻度压缩（需 scour）；2=深度压缩（默认，需 scour）。scour 未安装时自动降级为 0 |

引号处理规则（详见 [`引号处理规则.md`](引号处理规则.md)）：

| Shell | 推荐写法 |
|-------|---------|
| **cmd.exe** | `pty-agent exec test -c "python -c \"import time; print('done')\"" --idle-timeout 3` |
| **PowerShell 5.1 / pwsh 7+** | `pty-agent exec test -c 'python -c "import time; print(''done'')"' --idle-timeout 3` |
| **Git Bash** | `pty-agent exec test -c "python -c \"import time; print('done')\"" --idle-timeout 3` |

> 脚本内置了 `CommandLineToArgvW` 引号修复机制，但 PowerShell 下 `\"` 不转义，
> **推荐 PowerShell/pwsh 用户始终用外层单引号 + 内层双引号**，避免嵌套引号问题。

> 进程崩溃自动返回：`exec`/`send` 等待触发期间若检测到子进程崩溃，**立即返回**，triggerReturnReason 为 `"program_crashed"`，输出中附带崩溃事件。
>
> 输出静默超时：`--idle-timeout` 检测程序持续 N 秒无新输出时，返回 triggerReturnReason 为 `"idle_timeout"`。

### send — 发送输入

```powershell
pty-agent send myid "print('hello')" -t ">>>"
```

参数同 exec（不含 `--command`），但增加 `input` 位置参数。

**默认 raw 模式**：输入文本原样发送，不做任何转义处理。Windows 路径中的反斜杠（如 `C:\Users\rikka\new_folder`）不会被误转换。

**JSON + 控制字符转义模式**（`-j`/`--json-escaping`）：启用后先进行 JSON 反转移，再展开 `{...}` 控制字符语法，适用于发送多行代码或模拟按键：

| JSON 转义 | 含义 | 示例 |
|------|------|------|
| `\n` | 换行 | `"for i in range(3):\n    print(i)"` → 两行代码 |
| `\t` | 制表符 | `"print\t1"` |
| `\\` | 反斜杠 | `"C:\\\\path"` |
| `\"` | 双引号 | `"He said \\"hi\\""` |
| `\uXXXX` | Unicode | `"\\u4f60\\u597d"` → `"你好"` |

**控制字符语法**：

| 写法 | 输出 | 说明 |
|------|------|------|
| `{ctrl+a}` | `\x01` | Ctrl+字母 → ASCII 控制字符 |
| `{ctrl+alt+s}` | `\x1b\x13` | 多个修饰键用 `+` 连接；`alt` 前缀 ESC |
| `{ctrl+alt+shift+s}` | `\x01` | `shift` 对 Ctrl+字母 无额外影响 |
| `{enter}` | `\r` | 回车 |
| `{tab}` | `\t` | 制表符 |
| `{up}` / `{down}` / `{left}` / `{right}` | `\e[A` / `\e[B` / `\e[D` / `\e[C` | 方向键 |
| `{home}` / `{end}` | `\e[1~` / `\e[4~` | |
| `{pageup}` / `{pagedown}` | `\e[5~` / `\e[6~` | |
| `{insert}` / `{delete}` | `\e[2~` / `\e[3~` | |
| `{f1}` ~ `{f12}` | `\eOP` ~ `\e[24~` | 功能键 |

字面量 `{` 或 `}` 使用反引号转义：`` `{ ``、`` `} ``。名称大小写不敏感。

**行尾符配置**（`-e`/`--send-eol` 或 `--default send-eol`）：控制 send 末尾追加的行尾符，默认追加 `\r`。

| 名称 | 追加内容 | 适用场景 |
|------|----------|----------|
| `cr`（默认） | `\r` | PTY 模式下发送回车键 |
| `lf` | `\n` | 通用：REPL、命令行程序 |
| `crlf` | `\r\n` | 某些 Windows 程序需要 |
| `none` | 不追加 | TUI 程序方向键等纯按键序列 |

**快照输出**（`--snapshot`）：`send` 可加 `--snapshot`，返回终端屏幕快照而非原始 VT 序列输出。非 snapshot-mode 会话也可使用。snapshot-mode 会话下自动返回快照，无需此参数。

**快照差异**（`-s`/`--snapshot-diff`）：仅返回屏幕变化的行（需搭配 `--snapshot` 或 `--snapshot-mode`，与 `--response-format svg` 互斥）。首次调用返回完整快照，后续只返回变化行，格式为 `行号:内容`（行号从0开始）。无变化时 `outputStream` 为空。

**文件输出**（`-o`/`--output`）：send 子命令支持 `--output/-o <path>` 将终端快照渲染到文件，用法与 exec/read 一致。

**响应格式**（`--response-format`）：`stream`（默认）或 `svg`（返回 SVG 矢量图，需 PTY 会话的屏幕缓冲区）。对有 ConPTY 的 session，`--response-format svg` 会自动请求屏幕缓冲区数据。

**SVG 压缩**（`--svg-compression-level`）：0=不压缩；1=轻度；2=深度（默认）。需 scour，未安装时降级为 0。

当输入已以 `\n` 或 `\r` 结尾时不重复追加。

```powershell
# 默认行为（追加 \r）
pty-agent send myid "print('hello')" -t ">>>"

# TUI 程序：发送方向键，不追加换行
pty-agent send myid "{down}" -j -e none

# PTY 模式：发送回车键
pty-agent send myid "{enter}" -j -e none

# 追加 \r\n
pty-agent send myid "hello" -e crlf
```

```powershell
# raw 模式（默认）：路径原样发送
pty-agent send py "open('C:\Users\rikka\new_folder\test.txt')" -t ">>>"

# JSON 转义模式：\n 转为真正换行，发送多行代码
pty-agent send py "for i in range(3):\n    print(i)" -j -t ">>>"

# 控制字符：在 vim 中输入 :q 并回车
pty-agent send vim ":q{enter}" -j -e none

# 控制字符：发送 Ctrl+C
pty-agent send myid "{ctrl+c}" -e none
```

### read — 读取输出

```powershell
pty-agent read myid                    # 读取全部新输出
pty-agent read myid --full             # 读取全部累积输出
pty-agent read myid --offset 128       # 从指定字节偏移开始读
pty-agent read myid -i 5               # 读取最后 5 行
pty-agent read myid -i 10:20           # 读取第 10~20 行
pty-agent read myid -g "Error"         # 只显示匹配行
```

| 参数 | 说明 |
|------|------|
| `--full` | 返回全部累积输出而非仅新输出 |
| `--offset <bytes>` | 从指定字节偏移开始增量读取 |
| `-i`/`--lines <N>` | 最后 N 行；`start:end` 为范围行 |
| `-g`/`--grep <regex>` | 正则匹配过滤行 |
| `--keep-ansi` | 保留终端颜色/样式码（默认过滤） |
| `--encoding` | 终端编码，默认自动探测或本次调用记忆 |
| `--snapshot` | 返回终端屏幕快照（解析 VT 序列为可见文本）。非 snapshot-mode 会话也可使用。snapshot-mode 会话下自动返回快照，无需此参数 |
| `-s, --snapshot-diff` | 仅返回屏幕变化的行（需快照模式，stream 格式；首次返回完整快照，后续只返回变化行，格式为 `行号:内容`；与 `--response-format svg` 互斥） |
| `-o, --output <path>` | 输出到文件：`.svg`=矢量图（零依赖）；`.png`/`.jpg`/`.bmp`=位图（需 Pillow，Windows 下 GDI+BuiltinGlyphs 几何图元渲染消除字符间隙）；`.txt`/其他=纯文本（非 snapshot 模式下直接写入 outputStream，不是屏幕快照）。图片输出需搭配 `--snapshot` 或 `--snapshot-mode` |
| `--response-format <stream\|svg>` | 响应格式选择：`stream`=默认 JSON 格式输出；`svg`=返回 SVG 矢量图（JSON 包装，需 PTY 会话的屏幕缓冲区） |
| `--svg-compression-level <0\|1\|2>` | SVG 压缩等级：0=不压缩；1=轻度压缩（需 scour）；2=深度压缩（默认，需 scour）。scour 未安装时自动降级为 0 |

### list — 列出会话

```powershell
pty-agent list
```

JSON 输出示例：
```json
{"commandType":"list","sessions":[{"id":"web","rawStartCommand":"python -i -u","running":true,"pendingEvents":3}],"hint":""}
```

### events — 查看事件

```powershell
pty-agent events myid                          # 查看事件历史 + 当前待处理事件（events 命令本身不消费事件；事件在 exec/send/mouse 返回时被消费）
pty-agent events myid --since "18:00"           # 18:00 之后的事件
pty-agent events myid -l 5                      # 最近 5 条事件
pty-agent events myid --since "2026-06-07T18:00:00" --until "2026-06-07T18:30:00"
```

> `--since` / `--until` 支持完整 ISO 8601（如 `"2026-06-07T18:00:00"`）或简写 `"HH:MM"`（自动取当天日期）。

JSON 输出示例：
```json
{
  "commandType": "events",
  "sessionId": "myid",
  "pendingEvents": [
    {"time":"2026-06-22T14:32:15.47","type":"process_spawn","pid":11888,"currentlyActive":false,"detail":{"path":"C:\\Python311\\python.exe"}},
    {"time":"2026-06-22T14:32:16.89","type":"process_crash","pid":14708,"currentlyActive":false,"detail":{"exitCode":1,"errorMessage":"STATUS_ACCESS_VIOLATION"}}
  ],
  "count": 2,
  "hint": "Events are consumed when exec/send/mouse commands return. Below are pending events captured at that time."
}
```

> **存在性检测**：每个事件附带 `currentlyActive` 字段，标明进程/窗口当前是否仍然存活。`process_exit` / `process_crash` 事件固定为 `false`，`process_spawn` 实时检测 PID 是否在进程列表中。

### kill — 终止会话

```powershell
pty-agent kill myid      # 终止会话（KILL_ON_JOB_CLOSE 清理进程树）
```

### closewin — 关闭 GUI 窗口

```powershell
pty-agent closewin myid 0x001403AA       # 十六进制窗口句柄
pty-agent closewin myid 1313450         # 十进制窗口句柄
```

`<hwnd>` 参数支持十进制或 `0x` 十六进制格式。通过 `SendMessage(WM_CLOSE)` 关闭窗口。如果无效，`kill` 会话也可清理。

### mouse — 发送鼠标动作

仅支持 **屏幕快照模式** 的会话（`program.ptyType` 为 `conpty`/`unix-pty`，且 exec 时使用了 `--snapshot-mode` 或 `--default always-return-snapshot`）。坐标采用 **1-based `(col,row)`**，与 SGR 鼠标协议一致。

```powershell
# 单击 / 双击 / 三击
pty-agent mouse myid click 10,5
pty-agent mouse myid click 10,5 --button right --count 2 --ctrl --shift

# 拖拽（逐格移动）
pty-agent mouse myid drag 10,5 30,5 --button left

# 滚轮上下滚动 N 次
pty-agent mouse myid scroll 10,5 down 3

# 悬停
pty-agent mouse myid hover 10,5

# 长按 N 秒
pty-agent mouse myid press 10,5 2.0 --button middle

# 纯 grep：返回所有匹配的首/尾坐标
pty-agent mouse myid grep "Error"

# 获取光标位置及所在行内容
pty-agent mouse myid _get_cursor_location

# 用 grep 自动定位并执行动作（单匹配时执行；多匹配时返回坐标不执行）
pty-agent mouse myid click --grep "OK"

# 发送点击后等待输出变化（mouse 始终返回屏幕快照）
pty-agent mouse myid click 10,5 --timeout 5

# 发送点击后等待指定提示符返回
pty-agent mouse myid click 10,5 -t ">>>" --timeout 10
```

| 动作 | 位置参数 | 选项 |
|------|----------|------|
| `click` | `<coordinates>` | `--button`, `--count`, `--ctrl`, `--shift`, `--alt`, `--grep` |
| `drag` | `<from> <to>` | `--button`, `--ctrl`, `--shift`, `--alt`, `--grep` |
| `scroll` | `<coordinates> <up\|down> <times>` | `--ctrl`, `--shift`, `--alt`, `--grep` |
| `hover` | `<coordinates>` | `--ctrl`, `--shift`, `--alt`, `--grep` |
| `press` | `<coordinates> <seconds>` | `--button`, `--ctrl`, `--shift`, `--alt`, `--grep` |
| `grep` | `<pattern>` | 无 |
| `_get_cursor_location` | 无 | 无 |

此外支持 send/read 风格的**输出控制选项**：

| 选项 | 说明 |
|------|------|
| `-t/--trigger <regex>` | 命中正则后返回 |
| `--newline` | 仅在换行后检查 trigger |
| `--timeout <seconds>` | 等待超时（默认 120） |
| `--idle-timeout <seconds>` | 输出静默超时 |
| `--idle-after-first-output` | 首次输出后才开始检测静默超时 |
| `--keep-ansi` | 保留 ANSI 转义序列 |
| `-s/--snapshot-diff` | 仅返回屏幕变化的行 |
| `-o/--output <path>` | 输出到文件（.txt/.svg/.png 等） |
| `--response-format <stream\|svg>` | 返回 SVG 矢量图（需屏幕缓冲区） |
| `--svg-compression-level <0\|1\|2>` | SVG 压缩等级 |

坐标说明：
- `col` 为列号（从左到右 1 开始），`row` 为行号（从上到下 1 开始）。
- 终端尺寸固定为 80×24，越界会报错。

`--grep` 行为：
- 未提供坐标而提供 `--grep` 时，从当前终端屏幕快照匹配文本。
- **单匹配**：自动用匹配首坐标执行动作。
- **多匹配**：不执行动作，返回所有 `{"start":{"col":x,"row":y},"end":...}` 坐标。
- **无匹配**：返回错误。
- `grep` 动作本身为纯查询模式，始终返回坐标列表。

修饰键组合：
- `--ctrl`、`--shift`、`--alt` 可单独或组合使用。
- 对应 SGR 按钮值的修饰位 / Windows 控制台 control_key_state。

响应字段：
- `commandType`: `"mouse"`
- `performed`: `true` / `false`
- `matches`: grep 匹配到的坐标数组（如有）
- `cursor`: 光标位置及行内容（`_get_cursor_location` 时返回，含 `col`/`row`/`line`）
- `error`: 错误信息（如有）
- `program`: 会话状态

## 输出格式

仅支持 **JSON 模式**：stdout 每行输出一个 JSON 对象，便于 AI agent 解析。

### 命令响应

- **exec/send/read**: `commandType` 为 `exec`/`send`/`read`
  - 使用 `outputStream` + `outputOffset`（单流）
  - `triggerReturnReason`: 返回原因（`trigger_matched`/`trigger_timeout`/`idle_timeout`/`program_ended`/`gui_detected`/`program_crashed`/`ok`）
  - `program`: 含 `rawStartCommand`/`startTime`/`nowTime`/`running`/`ptyType`/`exitCode`/`errorMessage`
  - `program.debugInformation`: 含 `processes`/`guiWindows`/`pendingEvents`（`--no-debug` 时移除）
  - `hint`: 人类可读的返回原因描述
- **list**: `commandType` 为 `list`
- **events**: `commandType` 为 `events`
- **kill**: `commandType` 为 `kill`
- **closewin**: `commandType` 为 `closewin`
- **stop**: `commandType` 为 `stop`
- **error**: `type` 为 `error`

### 非命令响应

| 场景 | JSON 格式 | 示例 |
|------|-----------|------|
| 守护进程启停信息 | `{"type": "info", "message": "..."}` | `{"type":"info","message":"[pty-agent] Daemon started (port 12345)"}` |
| 配置查询（`--show-config`） | `{"type": "config", "content": "..."}` | `{"type":"config","content":"当前调用配置:\n  timeout = 120.0"}` |
| 帮助文本（无子命令） | `{"type": "help", "content": "..."}` | `{"type":"help","content":"usage: pty-agent ..."}` |
| 警告信息 | `{"type": "warning", "message": "..."}` | `{"type":"warning","message":"--idle-after-first-output 需要配合 --idle-timeout 使用"}` |

> 注：守护进程日志（`_logger.warning` 等）不会泄漏到 stderr。当 `DAEMON_LOG_LEVEL=None` 时，所有守护进程 logger 配置 `NullHandler` + `propagate=False`，阻止 Python lastResort handler 输出。

### SVG 格式

`--response-format svg` 时，响应格式为 `{"type": "svg", "data": "<svg>...</svg>"}`。需搭配 PTY 会话的屏幕缓冲区（exec: `--snapshot-mode`; send/read: `--snapshot`; 或 `--default always-return-snapshot on`）。对有 ConPTY 的 session，`--response-format svg` 会自动请求屏幕缓冲区数据。

SVG 压缩等级通过 `--svg-compression-level` 控制：

| 等级 | 说明 | 依赖 |
|------|------|------|
| 0 | 不压缩，仅移除空标签 | 无 |
| 1 | 轻度压缩（保留换行缩进，digits=5） | scour |
| 2 | 深度压缩（strip prolog, shorten ids, digits=3，默认） | scour |

注：scour 未安装时自动降级为 level 0。安装: `pip install scour`

## 进程崩溃自动返回机制

当 `exec` 或 `send` 等待触发时，后台机制实时检测进程状态：

1. **IOCP 实时通知**（Windows Job Object）：进程崩溃时即时推送通知，进程监控器立即设置崩溃标志
2. **监控线程每 2 秒轮询补全**：补充检测 IOCP 未覆盖的进程变更和 GUI 窗口
3. `wait_for_trigger` 轮询循环（每 0.1s）优先检测崩溃标志，检测到后立即返回 `triggerReturnReason="program_crashed"`
4. 响应中 `program.debugInformation.pendingEvents` 包含 crash 事件详情

**不依赖读线程 EOF 检测**，崩溃后即时返回，无需等待超时或输出触发。

## FAQ

| 问题 | 解决 |
|------|------|
| `python -u` 不出 `>>>` | 用 `python -i -u`（强制交互模式） |
| 会话卡住 | `pty-agent kill <id>` |
| 守护进程无响应 | `pty-agent stop; pty-agent start` |
| 中文乱码 | `--encoding gbk`（本次调用记忆） |
| 端口冲突 | 端口是动态分配的，用 `pty-agent stop; pty-agent start` 即可更换端口 |
| send 触发总超时（reader 竞态） | v0.6.0 已修复：内部已将 `set_trigger` 移至 `write_input` 之前，避免 reader 抢读响应后触发置在缓冲区末尾 |
| 需要"程序执行完静默后返回" | 使用 `--idle-timeout <秒>`，程序 N 秒无输出即返回。无需配合 `--trigger`。配合 `--idle-after-first-output` 可先等程序启动再检测静默 |
| 需要完整伪终端（ConPTY） | 命令自动拆为列表传给后端，响应 `program.ptyType` 为 `conpty` |
| 子进程需要特定环境变量 | 使用 `--env KEY=VALUE`，可多次指定。如 `--env TERM=xterm-256color --env COLORTERM=truecolor` |
| 响应中的 `ptyType` 是什么 | 标识当前会话使用的 PTY 后端：`conpty`（CreatePseudoConsole）、`unix-pty`（Unix PTY） |
| 进程树显示完整路径 | `debugInformation.processes` 中 `path` 字段为可执行文件的完整路径 |
| send/exec 返回值带哪些信息 | 返回 `triggerReturnReason`（字符串）+ `program`（含 rawStartCommand/startTime/nowTime/ptyType）+ `program.debugInformation.pendingEvents`（待处理事件）+ `hint`（人类可读描述） |
| PowerShell 下 `exec -c "python -c \"...\""` 报错 | PowerShell 的 `\"` 不会转义引号（`\` 是字面量），导致参数被拆分。推荐外层用单引号 `'...'` 或双写 `""`。详见 [`引号处理规则.md`](引号处理规则.md) |
| `send` 输入中的 `\n` 不换行 | 默认 raw 模式不处理转义，需加 `--json-escaping` 启用 JSON 转义解码 |
| 响应中 debug 信息过多 | 使用 `--no-debug` 或 `--default debug off` 禁用 debugInformation 输出 |
| stdout 和 stderr 的区别 | PTY 模式下 stderr 合并到 stdout，使用 `outputStream` 单流输出 |
| TUI 程序输出是乱码 VT 序列 | 使用 `--snapshot-mode`，所有输出返回终端屏幕快照；或使用 `--snapshot` 单次获取快照 |
| 需要所有会话都默认返回快照 | 使用 `--default always-return-snapshot on`，自动启用 snapshot-mode |
