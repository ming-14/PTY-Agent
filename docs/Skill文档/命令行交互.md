# pty-agent 命令行交互参考

> 完整命令参考，面向**终端用户**。开发指南见 [`../instruction.md`](../instruction.md)。

---

## 通用选项

以下选项适用于所有子命令（`start` / `stop` / `exec` / `send` / `read` / `list` / `remove` / `closewin`），**放子命令前后均可**：

| 选项 | 说明 |
|------|------|
| `--no-debug` | 禁用响应中的 debug 输出（进程树/GUI 窗口/事件） |
| `--show-config [KEY]` | 查看当前调用配置值 |
| `--default <KEY> <VALUE>` | 临时覆盖本次调用的默认配置（可用键：`timeout`/`newline`/`debug`，`<VALUE>` 是配置值或 `on`/`off`；不持久化） |

示例：
```powershell
pty-agent --no-debug exec test -c "cmd" -t "ok"
pty-agent exec test -c "cmd" -t "ok" --no-debug
```

## 两种后端模式

| 模式 | 选择 | 说明 |
|------|------|------|
| **subprocess**（默认） | 不传 `--pty` | `subprocess.Popen` stdin/stdout/stderr 管道；输出为原始文本流（原样透传）；支持 `--shell` 与 shell 语法 |
| **pty** | `--pty` | Windows ConPTY / Unix openpty 真实终端；命令自动拆为列表执行（**无 shell 语法**）；输出经 pyte 终端仿真解析（滚动历史 + 可见屏幕）；创建失败直接报错，**不回退** subprocess |

## 命令一览

```
pty-agent [通用选项] start                        启动守护进程
pty-agent [通用选项] stop                         停止守护进程
pty-agent [通用选项] list                         列出所有会话
pty-agent [通用选项] exec <id> -c "<cmd>"         启动会话
pty-agent [通用选项] send <id> "<输入>"            发送输入
pty-agent [通用选项] read <id>                    读取输出
pty-agent [通用选项] remove <id>                  移除会话
pty-agent [通用选项] closewin <id> <hwnd>         关闭 GUI 窗口
```

> 自动启动：首次执行 `exec`/`send`/`read`/`list` 等命令时，若守护进程未运行，客户端自动启动守护进程。

## 命令详解

### start / stop

```powershell
pty-agent start        # 启动后台守护进程
pty-agent stop         # 停止守护进程
```

### exec — 执行命令

```powershell
pty-agent exec myid -c "python -i -u" -t ">>>" --timeout 10
```

| 参数 | 说明 |
|------|------|
| `-c, --command` | **必填**。要执行的命令字符串（subprocess 模式经 shell 执行，支持 `&&`、`2>&1`、`\|` 等语法） |
| `--pty` | 启用真实终端：命令自动拆为列表（走 ConPTY/openpty），**不支持 shell 语法** `\| && >` 等 |
| `--force-pty-mode` | 强制模式：忽略 `--pty` 的 shell 操作符检测，原样执行 |
| `--shell` | 指定命令解释器：`powershell`（默认，不可用时回退 `cmd`）、`cmd`、`pwsh`、`bash`。**仅 subprocess 模式有效，与 `--pty` 互斥** |
| `-t, --trigger` | 触发条件（正则），匹配后返回输出（pty 模式在渲染文本上匹配） |
| `--timeout` | 等待超时秒数（默认 120，可通过 `--default timeout` 临时修改） |
| `--idle-timeout` | 输出静默超时（秒）。程序持续 N 秒无新输出时触发返回 |
| `--idle-after-first-output` | 仅在首次输出后才开始检测静默超时（初始不检测） |
| `--newline` | 仅在换行后检查触发 |
| `--full` | 返回全量输出而非增量输出 |

引号处理规则（详见 [`引号处理规则.md`](引号处理规则.md)）：

| Shell | 推荐写法 |
|-------|---------|
| **cmd.exe** | `pty-agent exec test -c "python -c \"import time; print('done')\"" --idle-timeout 3` |
| **PowerShell 5.1 / pwsh 7+** | `pty-agent exec test -c 'python -c "import time; print(''done'')"' --idle-timeout 3` |
| **Git Bash** | `pty-agent exec test -c "python -c \"import time; print('done')\"" --idle-timeout 3` |

> 进程崩溃自动返回：`exec`/`send` 等待触发期间若检测到子进程崩溃，**立即返回**，reason 为 `"crashed"`。
> 输出静默超时：`--idle-timeout` 检测程序持续 N 秒无新输出时返回 `"idle_timeout"`。

### send — 发送输入

```powershell
pty-agent send myid "print('hello')" -t ">>>"
```

参数同 exec（不含 `--command`），但增加 `input` 位置参数。输入文本原样发送（raw 模式），不转义。

### read — 读取输出（重构后语义）

```powershell
pty-agent read myid                          # pty: 可见屏幕 / subprocess: 完整缓冲
pty-agent read myid --full                   # 全量输出
pty-agent read myid --lines 5                # 全量最后 5 行
pty-agent read myid --lines 10:20            # 全量第 10~20 行
pty-agent read myid --grep "Error"           # 全量行正则过滤
```

| 参数 | 说明 |
|------|------|
| （无参数） | pty 模式＝可见屏幕（滚动历史之外的当前屏幕）；subprocess 模式＝完整缓冲 |
| `--full` | 返回**全量输出**（pty: 滚动历史 + 可见屏幕；subprocess: 完整缓冲） |
| `--lines <N>` | 全量输出最后 N 行；`start:end` 为范围行 |
| `--grep <regex>` | 全量输出行正则过滤 |
| ~~`--offset`~~ | **已删除**（不再支持增量字节读取） |

### list — 列出会话

```powershell
pty-agent list
```

输出示例：
```
# ── sessions (2) ──────
#   [web] python -i -u  [running, pending 3]
#   [gcc] g++ main.cpp  [ended]
```

### remove — 移除会话

```powershell
pty-agent remove myid   # 移除会话（KILL_ON_JOB_CLOSE 清理进程树）
```

### closewin — 关闭 GUI 窗口

```powershell
pty-agent closewin myid 0x001403AA       # 十六进制窗口句柄
pty-agent closewin myid 1313450          # 十进制窗口句柄
```

## 输出格式

程序实际输出 → **stdout**（纯文本）；元数据/调试信息 → **stdout**（纯文本）。

```
程序输出文本                     ← stdout（实际输出）

# ── session ────────────────────────
# matched | running                ← stdout（元数据）
# session id: 3e8a1f2c
# mode: subprocess | pty             ← 后端模式
# pty type: subprocess | win-conpty | unix-pty
# program: python -i -u
# started at: 2026-06-08 09:15:30
# current time: 2026-06-08 09:18:00
# ── debug ────────────────────────
# process tree: PID 1234 (C:\Python311\python.exe)
# ── events (2) ────────
# [+]  [22:52:00] PID 5678 创建
```

`--no-debug` 或 `--default debug off` 时隐藏 debug/events 段。

## FAQ

| 问题 | 解决 |
|------|------|
| `python -u` 不出 `>>>` | 用 `python -i -u`（强制交互模式）；pty 模式下推荐 `-u`/显式 flush 观察流式输出 |
| 会话卡住 | `pty-agent remove <id>` |
| 守护进程无响应 | `pty-agent stop; pty-agent start` |
| pty 模式命令含 `\| && >` 报错 | pty 是真实终端，命令拆为列表执行；去掉 `--pty` 用 subprocess（可 shell 语法）或加 `--force-pty-mode` |
| read 拿不到历史 | pty 模式默认返回可见屏幕；需要历史用 `--full`/`--lines`/`--grep`（基于全量输出） |
| 增量读取 | 已删除 `--offset`；触发返回（exec/send 的 `-t`）自带内部游标增量 |
