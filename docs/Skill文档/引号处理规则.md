# 引号处理规则

> 适用范围：所有"值里带引号"的选项 —— `exec -c "<command>"` 与 `send -i "<content>"`
> 规则完全相同（两者都是传给本 CLI 的带值选项），下文示例用 `-c` 书写，
> 换成 `-i` 同理。

## 命令行嵌套引号

### cmd.exe

```powershell
pty-agent exec test -c "python -c \"import time; print('done')\"" --idle-timeout 3
pty-agent send test -i "print(\"hi\")" -t ">>>"
```

cmd.exe 写 `\"` 嵌套：`-c "python -c \"print(1)\""` / `-i "print(\"1\")"`

> 若 `-c` / `-i` 的值被 shell 截短，CLI 会用 Windows 原生
> `CommandLineToArgvW` 重新解析整条命令行并纠偏（`src/__main__.py`
> `_fix_windows_quoting`）；该纠偏只覆盖 cmd.exe 风格，PowerShell 仍需按下节写法。

### PowerShell 5.1 / pwsh 7+

```powershell
pty-agent exec test -c 'python -c "import time; print(''done'')"' --idle-timeout 3
pty-agent send test -i 'print("hi")' -t ">>>"
```

PowerShell 外层单引号，内层双引号：`-c 'python -c "print(1)"'` / `-i 'print("hi")'`

PowerShell 的 `\"` 不转义（`\` 是字面量），推荐 PowerShell/pwsh 用户始终用外层单引号 + 内层双引号，避免嵌套引号问题。

### Git Bash

```powershell
pty-agent exec test -c "python -c \"import time; print('done')\"" --idle-timeout 3
pty-agent send test -i "print(\"hi\")" -t ">>>"
```

## 值以 `-` 开头时

`-i` / `-c` 的值若以 `-` 开头（如 `--help`、`-v`），用 `=` 形式传入，避免被当作选项：

```powershell
pty-agent send gdb -i="--help" -t "\(gdb\)"
pty-agent send gdb --input="-break-main" -t "\(gdb\)"
```
