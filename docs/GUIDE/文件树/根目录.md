## 根目录

```
PTY-Agent/
├── app.py                 # CLI 快捷入口（等同于 python -m src）
├── BUILD.ps1              # 构建打包脚本
├── start.ps1              # 启动守护进程脚本（PowerShell）
├── stop.ps1               # 停止守护进程脚本（PowerShell）
├── restart.ps1            # 重启守护进程脚本（PowerShell）
├── start.sh               # 启动守护进程脚本（Unix）
├── stop.sh                # 停止守护进程脚本（Unix）
├── restart.sh             # 重启守护进程脚本（Unix）
├── requirements.txt       # Python 依赖声明
├── pytest.ini             # pytest 配置
├── README.md              # 项目说明
├── AGENTS.md              # AI Agent 工作规范
├── SKILL.md               # AI 技能描述
├── 文件树.md              # 本文档（目录结构说明）
├── .gitignore             # Git 忽略规则
├── .gitattributes         # Git 属性（含行尾/二进制标记）
├── .git/                  # Git 版本库
├── .agents/               # 隐藏目录：Agent 本地技能（skills/download-by-mirror、skills/python-win32api）
├── docs/                  # 设计文档
├── src/                   # 主包
├── tests/                 # 测试套件
├── bin/                   # 辅助工具
├── fastscreen/            # C++ 屏幕捕获 DLL 源码 + Python 封装
└── web_rime/              # Rime WASM 输入法插件源码
```

> 说明：原文档中的 `fastscreen_source/`、`web-rime_source/`、`reference/`、`LICENSE` 均不存在——真实目录名为 `fastscreen/`、`web_rime/`；仓库无 `LICENSE` 文件；`reference/` 参考目录未纳入本仓库。
