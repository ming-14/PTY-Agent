# PTY-Agent 功能全景图

> 基于源码 `src/` 目录逐文件追踪，覆盖所有 CLI 命令、WebSocket 消息、HTTP 端点、守护进程 Handler、PTY 后端、认证机制、终端模拟、进程管理等全部功能。

## 1. CLI 命令体系（`python -m src` / `app.py`）

### 1.1 全局选项
| 选项 | 说明 |
|------|------|
| `--show-config [KEY]` | 查看配置值（不指定 KEY 则显示全部） |
| `--host HOST` | 远程 daemon 主机地址（pubkey 跨机 TLS 模式） |
| `--port PORT` | 远程 daemon TLS 端口（pubkey 跨机 TLS 模式） |

### 1.2 所有子命令公共选项
| 选项 | 说明 |
||------|
| `--encoding ENC` | 终端编码（如 utf-8、gbk），本次调用记忆 |
| `--default KEY VALUE` | 设置默认配置（可多次指定） |
| `--no-debug` | 禁用响应中的 debugInformation 输出 |

### 1.3 `start` — 启动后台守护进程
- 自动检测守护进程是否已运行
- 已运行时返回当前会话列表
- 未运行时自动启动守护进程子进程

### 1.4 `stop` — 停止后台守护进程
| 选项 | 说明 |
|------|------|
| `--force / -f` | 强制清理（端口丢失时通过互斥锁定位并终止守护进程） |

### 1.5 `status` — 查看守护进程运行状态
- 返回 running/pid/port 信息

### 1.6 `list` — 列出所有活跃会话
- 返回所有活跃会话的 id/command/running 状态

### 1.7 `exec` — 启动或附加到会话
| 选项 | 说明 |
|------|------|
| `id` (位置参数) | 会话标识 |
| `--command / -c CMD` | 要执行的命令字符串（自动拆分为参数列表） |
| `--force-pty-mode` | 强制模式：忽略 shell 操作符检测，原样拆分执行 |
| `--trigger / -t PATTERN` | 触发条件（正则表达式），命中后返回输出 |
| `--newline` | 仅在换行后才检查触发条件 |
| `--timeout SECS` | 等待超时秒数（默认 120） |
| `--idle-timeout SECS` | 输出静默超时（秒），程序持续 N 秒无新输出时触发返回 |
| `--idle-after-first-output` | 仅在程序首次输出后才开始检测静默超时 |
| `--full` | 返回全部累积输出而非仅新输出 |
| `--keep-ansi` | 保留终端颜色/样式码（默认过滤） |
| `--cwd DIR` | 指定子进程工作目录 |
| `--env KEY=VALUE...` | 子进程环境变量（可指定多个） |
| `--snapshot-mode` | 快照模式：禁用 trigger/idle-timeout，所有输出返回终端屏幕快照 |
| `--size WxH` | 终端尺寸（如 120x40，默认 80x24） |
| `--snapshot-diff / -s` | 仅返回屏幕变化的行（需快照模式） |
| `--output / -o PATH` | 输出到文件（.txt/.log=纯文本; .svg=矢量图; .png/.jpg/.bmp=位图） |
| `--response-format {stream,svg}` | 响应格式（svg 需屏幕快照模式） |
| `--svg-compression-level {0,1,2}` | SVG 压缩等级（0=不压缩; 1=轻度; 2=深度） |

### 1.8 `send` — 向运行中的会话发送输入
| 选项 | 说明 |
|------|------|
| `id` (位置参数) | 会话标识 |
| `input` (位置参数) | 要发送的输入文本 |
| `--trigger / -t PATTERN` | 触发条件（正则表达式） |
| `--newline` | 仅在换行后检查触发条件 |
| `--timeout SECS` | 等待超时秒数 |
| `--idle-timeout SECS` | 输出静默超时 |
| `--idle-after-first-output` | 仅首次输出后检测静默 |
| `--full` | 返回全部累积输出 |
| `--keep-ansi` | 保留 ANSI 颜色/样式码 |
| `--json-escaping / -j` | 启用 JSON + 控制字符转义解码（`\n`→换行; `{ctrl+a}`、`{enter}`、`{up}`、`{f1}` 等生成对应控制字符/VT 序列） |
| `--send-eol / -e {lf,crlf,cr,none}` | 末尾追加的行尾符（默认 cr=`\r`，模拟终端 Enter 键） |
| `--snapshot` | 返回终端屏幕快照而非原始 VT 序列输出 |
| `--snapshot-diff / -s` | 仅返回屏幕变化的行 |
| `--output / -o PATH` | 输出到文件 |
| `--response-format {stream,svg}` | 响应格式 |
| `--svg-compression-level {0,1,2}` | SVG 压缩等级 |

### 1.9 `read` — 读取会话终端输出
| 选项 | 说明 |
|------|------|
| `id` (位置参数) | 会话标识 |
| `--trigger / -t PATTERN` | 触发条件（正则表达式） |
| `--newline` | 仅在换行后检查触发条件 |
| `--timeout SECS` | 等待超时秒数 |
| `--idle-timeout SECS` | 输出静默超时 |
| `--idle-after-first-output` | 仅首次输出后检测静默 |
| `--lines / -l RANGE` | 行数过滤: N=最后N行, start:end=范围 |
| `--grep / -g PATTERN` | 正则匹配过滤行 |
| `--offset N` | 增量读取：从指定字节偏移开始 |
| `--full` | 返回全部累积输出 |
| `--keep-ansi` | 保留 ANSI 颜色/样式码 |
| `--snapshot` | 返回终端屏幕快照（用户真正看到的终端界面文本） |
| `--snapshot-diff / -s` | 仅返回屏幕变化的行 |
| `--output / -o PATH` | 输出到文件 |
| `--response-format {stream,svg}` | 响应格式 |
| `--svg-compression-level {0,1,2}` | SVG 压缩等级 |
| `--column N` | 输出第 N 列（1-based，仅 PTY 快照模式） |

### 1.10 `kill` — 终止指定会话
| 选项 | 说明 |
|------|------|
| `id` (位置参数) | 会话标识 |

### 1.11 `events` — 查看会话事件

### 1.12 `closewin` — 关闭指定 GUI 窗口

### 1.13 `mouse` — 发送鼠标动作到 PTY 会话
| 选项 | 说明 |
|------|------|
| `id` (位置参数) | 会话标识 |
| `action` (位置参数) | 鼠标动作类型: `click` / `drag` / `scroll` / `hover` / `press` / `grep` / `_get_cursor_location` |
| `args` (位置参数) | 动作位置参数（坐标 col,row 等） |
| `--button {left,right,middle}` | 鼠标按钮（默认 left） |
| `--count {1,2,3}` | 点击次数（默认 1，仅 click 有效） |
| `--ctrl` | 按住 Ctrl |
| `--shift` | 按住 Shift |
| `--alt` | 按住 Alt |
| `--grep PATTERN` | 用正则匹配终端屏幕内容获取坐标（多匹配时不执行动作） |
| `--trigger / -t PATTERN` | 触发条件（正则表达式） |
| `--newline` | 仅在换行后检查触发条件 |
| `--timeout SECS` | 等待超时秒数 |
| `--idle-timeout SECS` | 输出静默超时 |
| `--idle-after-first-output` | 仅首次输出后检测静默 |
| `--keep-ansi` | 保留 ANSI 颜色/样式码 |
| `--snapshot` | 返回终端屏幕快照 |
| `--snapshot-diff / -s` | 仅返回屏幕变化的行 |
| `--output / -o PATH` | 输出到文件 |
| `--response-format {stream,svg}` | 响应格式 |
| `--svg-compression-level {0,1,2}` | SVG 压缩等级 |

**鼠标动作子功能：**
- **click**: 点击指定坐标（col,row），支持按钮/点击次数/修饰键
- **drag**: 拖拽（从坐标 A 到坐标 B）
- **scroll**: 滚动（坐标 + 方向 up/down + 次数）
- **hover**: 悬停在指定坐标
- **press**: 长按（坐标 + 持续秒数）
- **grep**: 用正则匹配屏幕内容获取坐标（不执行动作，仅返回匹配坐标）
- **_get_cursor_location**: 返回光标位置（col,row）及所在行完整内容（不执行动作）
- **--grep 模式**: 任何动作都支持通过正则自动定位屏幕坐标

## 2. WebSocket 消息协议（前端 <-> 守护进程）

### 2.1 会话管理
| 消息类型 | 方向 | 说明 |
|----------|------|------|
| `ping` | 前端→后端 | 心跳检测 |
| `pong` | 后端→前端 | 心跳响应 |
| `list` | 前端→后端 | 列出所有活跃会话 |
| `session_list` | 后端→前端 | 会话列表响应 |

| `unsubscribe` | 前端→后端 | 取消订阅会话输出 |
| `kill` | 前端→后端 | 终止会话 |
| `session_ended` | 后端→前端 | 会话结束通知（exitCode + errorMessage） |
| `session_created` | 后端→前端 | 会话创建广播（给其他连接） |
| `session_removed` | 后端→前端 | 会话移除广播 |
| `session_detail` | 前端→后端 | 查询会话详情（进程树、事件、GUI 窗口等） |

## 5. PTY 后端（伪终端实现）

### 5.1 工厂函数 `create_pty()`
优先级:
- **Windows**: ConDrv 直连 > kernel32.CreatePseudoConsole (ConPTY)
- **Unix**: UnixPseudoTerminal

### 5.2 PseudoTerminal 抽象基类
所有后端必须实现:
- `read(n)` → bytes — 从 PTY 读取
- `write(data)` — 写入数据到 PTY
- `drain()` — 排空管道缓冲区（非阻塞）
- `resize(cols, rows)` — 调整终端尺寸
- `close()` — 关闭 PTY
- `fileno()` — 返回文件描述符
- `get_child_pid()` — 获取子进程 PID
- `get_exit_code()` — 获取退出码
- `get_process_list()` — 获取进程列表
- `get_gui_windows()` — 获取 GUI 窗口列表
- `poll_gui_windows()` — 轮询 GUI 窗口
- `close_gui_window(hwnd)` — 关闭 GUI 窗口
- `kill_tree()` — 强杀进程树
- `get_type()` — 返回后端类型标识

### 5.3 Windows PTY 实现
| 后端 | 类型标识 | 说明 |
|------|----------|------|
| `ConDrvPseudoTerminal` | `win-condrv` | ConDrv 直连（优先） |
| `WindowsPseudoTerminal` | `win-conpty` | kernel32.CreatePseudoConsole（ConPTY） |

Windows 特有功能:
- 进程树管理（Job Object）
- GUI 窗口检测与关闭
- Console 操控（AttachConsole/FreeConsole）
- Ctrl+C 信号发送（GenerateConsoleCtrlEvent）
- Windows 错误码翻译

### 5.4 Unix PTY 实现
| 后端 | 类型标识 | 说明 |
|------|----------|------|
| `UnixPseudoTerminal` | `unix-pty` | fork + pty.openpty |

Unix 特有功能:
- 进程树管理（os.kill 进程组）
- Shell 检测与格式化

### 5.5 Shell 检测
- `detect_available_shells()` — 检测系统可用 shell（平台自适应）
- `format_shell_info()` — 格式化 shell 信息字符串

## 6. 会话管理（Session）

### 6.1 Session 生命周期
- `start()` — 创建 PTY + 启动后台读者线程和监控线程
- `stop()` — 强杀进程树 + 关闭 PTY + 等待读者线程退出

### 6.2 Session 核心能力
| 功能 | 方法 | 说明 |
|------|------|------|
| 写入输入 | `write_input(data)` | 通过 InputInterceptor 拦截后写入 |
| 发送信号 | `send_signal(sig)` | 向子进程发送信号（如 SIGINT） |
| 获取输出 | `get_output(from_offset, encoding)` | 获取会话输出 |
| 屏幕快照 | `get_snapshot(keep_ansi)` | 获取终端屏幕快照 |
| 快照差异 | `get_snapshot_diff(keep_ansi)` | 获取与上次相比变化的行 |
| 光标序列 | `get_cursor_seq()` | 获取光标定位 VT 序列 |
| 光标位置 | `get_cursor_location()` | 获取光标位置（col,row）及所在行内容 |

## 12. 认证系统（Auth）

### 12.1 抽象接口
- `Authenticator` — 认证器抽象基类
- `CredentialProvider` — 凭证提供者抽象基类
- `MessageSigner` — 消息签名器抽象基类

### 12.2 Token 认证（同机模式）
| 组件 | 说明 |
|------|------|
| `TokenAuthenticator` | Token 认证器 |

### 12.4 密钥管理
- `PublicKey` — 公钥实体
- `PrivateKey` — 私钥实体（from_file / to_openssh_bytes / fingerprint）

### 12.5 TLS 基础设施

| `KnownHosts` | TOFU 信任存储（Trust On First Use） |
| `TLSClient` | TLS 客户端连接（TOFU 证书验证） |

### 12.6 认证模式
| 模式 | 说明 |
|------|------|
| `token` | HMAC 对称认证（同机，SHM 发现） |
| `pubkey` | Ed25519 公钥认证（跨机，TLS 传输） |
| `none` | 无认证 |

### 12.7 组合认证
- `CompositeAuthenticator` — 组合认证器（OR 语义，任一通过即放行）
- `OrVerifier` — OR 分发验证器（服务端入站多认证方式）
- `AuthContext` — 连接级认证上下文

## 20. 守护进程生命周期

### 20.1 启动流程
1. 单实例检查（SingleInstanceLock）
2. 端口动态分配（随机未占用端口）

3. 停止 Web 服务

5. 释放共享内存
6. 单实例锁释放

## 26. 辅助功能

### 26.1 命令行提示
- `_HintParser` — 智能错误提示（如误输入程序路径时提示用 exec 命令）
- `_TimeoutHintAction` — read 命令不支持 --timeout 的友好提示
- `_InputHintAction` — send 命令输入格式友好提示

### 26.2 时间解析
- `_maybe_expand_time()` — 支持 ISO 8601 和 HH:MM 格式

### 26.3 坐标解析
- `_parse_coords()` — 解析 'col,row' 坐标字符串

### 26.4 Shell 操作符检测
- `_has_shell_operators()` — 检测命令是否包含 shell 操作符（`|` `&` `>` `<` `&&` `||` `;`）

### 26.5 Windows 命令行修复
- `_fix_windows_exec_quoting()` — 修复 PowerShell/CMD 传递含空格路径时的引号问题
